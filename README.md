# Convertly Unit Converter

A lightweight unit converter built with plain HTML, CSS, and JavaScript. It
converts length, mass, and temperature directly in your browser.

## Run locally

Open `unit-converter.html` in a browser. No installation or build step is
required.

## Project files

- `unit-converter.html` — page structure and accessible converter controls
- `unit-converter.css` — responsive layout and styling
- `unit-converter.js` — conversion logic and interactive controls
