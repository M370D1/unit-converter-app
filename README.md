# Convertly Unit Converter

A lightweight unit converter built with plain HTML, CSS, and JavaScript. It
converts length, mass, temperature, and currency directly in your browser.

## Features

### Metric Converter
- **Length**: millimeters (mm), centimeters (cm), meters (m), kilometers (km), inches (in), feet (ft), miles (mi)
- **Mass**: milligrams (mg), grams (g), kilograms (kg), ounces (oz), pounds (lb)

### Temperature Converter
- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

### Currency Converter
- Real-time exchange rates via exchangerate-api.com
- Supported currencies: USD, EUR, GBP, JPY, CAD, AUD, CHF, CNY, INR, MXN
- Fallback rates for offline support

## Run locally

Open `unit-converter.html` in a browser. No installation or build step is
required.

## Project files

- `unit-converter.html` — page structure and accessible converter controls
- `unit-converter.css` — responsive layout and styling
- `unit-converter.js` — conversion logic, interactive controls, and real-time currency rate fetching
